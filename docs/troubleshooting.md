# 常见问题

## FD 或 SDK 找不到舵机

按以下顺序排查，且每次只改变一个条件：

1. 系统是否识别出正确 COM/串口，是否被其它程序占用。
2. 调试板是否匹配 TTL/RS485，USB 线是否支持数据。
3. 舵机是否由符合规格的外部电源供电，是否可靠共地。
4. 当前波特率是否正确；总线上是否有重复 ID。
5. 针序、A/B、信号线和接插件是否正确且接触可靠。
6. 只连接一只舵机，用 FD 与 SDK Ping 交叉验证。

## 能通信但不运动

- 动力电源可能电流不足或触发限流。
- 扭矩未启用，或设备处于不匹配的运行模式。
- 目标值落在软/硬限位之外，速度或扭矩参数为零。
- 使用了其它系列的寄存器、单位或数据长度。
- 温度、电压、过载等保护已经触发。

先读取状态和当前位置，再卸载机构做小范围测试。

## 舵机抖动或通信间歇失败

检查电源压降、共地、线长、接插件、分支拓扑、波特率和程序收发方向切换。动力线与敏感信号线合理布置，多机同时启动时尤其关注电源瞬态。

## 修改 ID/波特率后“消失”

断电重启，只连接该设备，并让 FD/SDK 切换到新波特率后重新搜索。若不确定修改结果，保存现场信息，不要连续盲写多个地址。

## 提交技术支持信息

请附：完整型号及标签照片、电源电压/限流、调试板型号、接线照片、ID、波特率、FD/SDK 版本、操作系统、最小复现程序、错误原文，以及故障发生前最后一个成功步骤。不要上传密码、令牌或私人信息。
