## 1 舵机通信协议

舵机使用FT-SCS自定义协议，舵机默认波特率为1M或500k使用TTL单总线通信，数据位8，无校验，停止位1；波特率可配置范围38400~1Mbps(500k)，默认通信地址（站号）为1。

[FT-SCS 自定义协议](../protocol/index.md)

## 3 特殊字节解释

### 3.1 舵机相位

**位数/位权重：说明**

- BIT0(1)：驱动方向相位；(0)正向，(1)反向
- BIT1(2)：----
- BIT2(4)：----
- BIT3(8)：速度模式；(0)速度0表示停止，(1)速度0表示最高速度
- BIT4(16)：----
- BIT5(32)：PWM相位，(0)同相，(1)反相
- BIT6(64)：电压模式，(0)1.5K低压采样，(1)1K高压采样
- BIT7(128)：----

!!! warning "提示"
    如果同时设置多个位，舵机的相位值为各个位值之和。

### 3.2 舵机状态

舵机状态：0表示正常，1表示异常

**位数/位权重：说明**

- BIT0(1)：电压状态
- BIT1(2)：----
- BIT2(4)：温度状态
- BIT3(8)：----
- BIT4(16)：----
- BIT5(32)：负载状态
- BIT6(64)：----
- BIT7(128)：----

!!! warning "提示"
    如果同时有多种状态，舵机的状态值为各个位值之和。例如：电压过压/欠压与舵机过热，则舵机状态值为4+1=5；

### 3.3 卸载条件

卸载条件：0表示关闭，1表示开启

**位数/位权重：说明**

- BIT0(1)：电压保护
- BIT1(2)：----
- BIT2(4)：过热保护
- BIT3(8)：----
- BIT4(16)：----
- BIT5(32)：负载过载
- BIT6(64)：----
- BIT7(128)：----

!!! warning "提示"
    如果同时设置多个位，舵机的卸载条件值为各位值之和。例如：电压保护与过热保护同时开启，则卸载条件值为4+1=5；

### 3.4 LED报警条件

LED报警条件：0表示关闭，1表示开启

**位数/位权重：说明**

- BIT0(1)：电压报警
- BIT1(2)：----
- BIT2(4)：过热报警
- BIT3(8)：----
- BIT4(16)：----
- BIT5(32)：负载过载报警
- BIT6(64)：----
- BIT7(128)：----

!!! warning "提示"
    如果同时设置多个位，舵机的LED报警条件值为各位值之和。例如：电压报警与过热报警同时开启，则报警条件值为4+1=5；
