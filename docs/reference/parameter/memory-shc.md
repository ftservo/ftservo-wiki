# SHC舵机-内存表解析

## 1 舵机通信协议

舵机使用CANopen通信协议，舵机默认CAN波特率为125k，波特率可配置范围20k~1Mbps，默认通信地址（节点）为1。

使用SDO指令可访问舵机所有字典对象实现舵机参数修改

使用PDO指令可快速控制舵机实现伺服功能

使用SYNC指令可快速同步反馈总线上所有舵机的实时状态

RPDO1默认映射控制字与舵机模式对象用于舵机扭矩开关与模式配置

RPDO2默认映射目标位置对象用于舵机伺服位置控制

RPDO3默认映射目标速度对象用于舵机伺服速度控制

RPDO4默认映射额定电流对象用于舵机伺服额定电流控制

TPDO2默认映射实时位置对象使用SYNC指令可实时反馈总线上所有舵机实时位置

TPDO1、TPDO3与TPDO4默认映射关闭

## 2 对象字典OD

CANopen对象字典(OD: Object Dictionary)是CANopen协议最为核心的概念。所谓的对象字典就是一个有序的对象组，描述了对应CANopen节点的所有参数，包括通讯数据的存放位置也列入其索引，对象字典通过索引与子索引进行寻址。

### 3.1 模式定义

### 3.2 错误寄存器定义

**位数/位权重**：0表示正常，1表示异常

- BIT3(8)：舵机过热
- BIT4(16)：----
- BIT5(32)：----
- BIT6(64)：----

### 3.4 舵机相位

**位数/位权重**：说明

- BIT0(1)：驱动方向相位；(0)正向，(1)反向
- BIT1(2)：位置反馈方向相位，(0)正向，(1)反向
- BIT2(4)：无刷/有刷，(0)无刷，(1)有刷，重启生效

### 3.5 舵机状态

\*舵机状态：0表示正常，1表示异常

**位数/位权重**：说明

- BIT0(1)：扭矩状态：0表示扭矩关闭，1表示扭矩打开
- BIT1(2)：移动状态：0舵机正在移动，1舵机停止移动
- BIT2(4)：目标状态：0舵机到达设定目标位置，1舵机没有到达设定目标位置

### 3.8 状态复位

故障复位：0无效，1表示复位

**位数/位权重**：说明

- BIT0(1)：----
- BIT1(2)：复位过流故障
- BIT2(4)：复位过压/欠压，电压恢复正常，状态复位写32复位过压/欠压状态
- BIT3(8)：复位过热状态，温度恢复正常，状态复位写64复位过热状态
- BIT4(16)：----
- BIT5(32)：----
- BIT6(64)：----
- BIT7(128)：复位磁编码状态，磁编码连接正常，状态复位写128复位磁编码状态
- BIT14(16384)：圈数复位，状态复位写16384，舵机当前位置恢复至单圈位置
- BIT15(32768)：中位设置；状态复位写32768，当前位置设置为8192中位
