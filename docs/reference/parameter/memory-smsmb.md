# 磁编码 SMSMB 舵机 - 内存表解析

适用于 SMSMB 系列串行舵机，使用 MODBUS-RTU 标准协议。MODBUS 保持寄存器为 16 位，双字节字段按**高字节在前**传输；「地址PLC」为对应的 MODBUS 保持寄存器地址(4xxxx)。

## 1 舵机通信协议

舵机使用MODBUS-RTU标准协议，出厂时的串口默认配置，波特率默认为115200，数据位 8，无校验，停止位 1；波特率可配置范围9600~256Kbps，默认通信地址（站号）为 1。

完整协议帧格式与指令集见[通信协议](../protocol/index.md)。

## 3 特殊字节解释

### 3.1 舵机相位

**位数/位权重**：说明

- BIT0(1)：驱动方向相位; (0)正向，(1)反向
- BIT1(2)：驱动桥模式; (0)无刷，(1)有刷，重启生效
- BIT2(4)：扭矩自动开关; (0)自动开启，(1)指令开启，固件>=20.9版本
- BIT3(8)：状态自动复位; (0)自动复位，(1)指令复位，固件>=20.9版本
- BIT4(16)：角度反馈模式; (0)反馈单圈角度，(1)反馈全角度
- BIT5(32)：----
- BIT6(64)：PWM频率，(0)24kHz，(1)16kHz
- BIT7(128)：位置反馈方向相位，(0)正向，(1)反向

!!! warning "提示"
    如果同时设置多个位，舵机的相位值为各个位值之和。例如：原相位值为0，舵机运行反向，则相位值为128+1=129；

### 3.2 舵机状态

舵机状态：0表示正常，1表示异常

**位数/位权重**：说明

- BIT0(1)：电压状态
- BIT1(2)：磁编码状态
- BIT2(4)：温度状态
- BIT3(8)：电流状态
- BIT4(16)：扭矩状态：0表示扭矩关闭，1表示扭矩打开
- BIT5(32)：负载状态

!!! warning "提示"
    如果同时有多种状态，舵机的状态值为各个位值之和。例如：电压过压/欠压与舵机过热，则舵机状态值为4+1=5；

### 3.3 保护开关

卸载条件：0表示关闭，1表示开启

**位数/位权重**：说明

- BIT0(1)：电压保护
- BIT1(2)：磁编码保护
- BIT2(4)：过热保护
- BIT3(8)：过流保护
- BIT4(16)：----
- BIT5(32)：负载过载

!!! warning "提示"
    如果同时设置多个位，舵机的卸载条件值为各位值之和。例如：电压保护与过热保护同时开启，则卸载条件值为4+1=5；

### 3.4 LED报警条件

LED报警条件：0表示关闭，1表示开启

**位数/位权重**：说明

- BIT0(1)：电压报警
- BIT1(2)：磁编码报警
- BIT2(4)：过热报警
- BIT3(8)：过流报警
- BIT4(16)：----
- BIT5(32)：负载过载报警

!!! warning "提示"
    如果同时设置多个位，舵机的LED报警条件值为各位值之和。例如：电压报警与过热报警同时开启，则报警条件值为4+1=5；

### 3.5 故障复位

故障复位：0无效，1表示复位

**位数/位权重**：说明

- BIT0(1)：复位过载故障; 自动复位开启，反向目标与关闭扭矩开关可复位故障
- BIT1(2)：复位过流故障; 自动复位开启，反向目标与关闭扭矩开关可复位故障
- BIT2(4)：中位设置，当前位置设置为2048中位
- BIT3(8)：----
- BIT4(16)：----
- BIT5(32)：复位过压/欠压，电压恢复正常，状态复位写32复位过压/欠压状态；自动复位开启，电压恢复正常自动复位
- BIT6(64)：复位过热状态，温度恢复正常，状态复位写64复位过热状态；自动复位开启，温度恢复正常自动复位
- BIT7(128)：复位磁编码状态，磁编码连接正常，状态复位写128复位磁编码状态；自动复位开启，磁编码连接正常自动复位

!!! warning "提示"
    如果同时设置多个位，复位过载故障与复位过流故障的值为各位值之和。例如：复位过载故障同时复位过流故障，则复位故障值为1+2=3；

!!! warning "不要跨系列套用地址"
    其他系列即使使用相同地址，含义也可能不同（例如 HLS 系列地址 44–45 为目标电流，而 SMSMB 系列地址 132–133 为扭矩限制）。请返回[通信协议](../protocol/index.md)选择正确的内存表。
