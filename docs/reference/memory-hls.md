# HLS 内存表

适用于 HLS 半双工 TTL 系列。16 位数据按低字节在前传输。HLS 地址 44–45 定义为目标扭矩，与 SMS/STS 的目标时间不同。

以下地址与飞特官方 SDK 的 `HLSCL` 应用层定义一致。双字节项目必须采用该应用层的字节顺序读写。

## 只读持久化区

| 地址 | 长度 | 名称 | 访问 |
| ---: | ---: | --- | --- |
| 3–4 | 2 字节 | 型号标识 | 只读 |

## 使用说明

- 地址以十进制表示；双字节字段占用起始地址和下一个连续地址。
- “持久化”字段会影响设备配置。修改 ID、波特率、模式、限位或偏移前，请记录原值并只连接一只舵机。
- 表中只列出官方 SDK 当前公开的常用地址。数值单位、范围、默认值和写入条件以具体型号资料及固件为准。
- 先读取型号标识与当前配置，再执行写入；首次运动采用低速、小位移和无负载环境。

!!! warning "不要跨系列套用地址"
    其他应用层即使使用相同地址，也可能具有不同含义。请返回[通信协议](protocol.md)选择正确的内存表。
