# HD-1910-C001

`HD-1910-C001` 是面向小型双足机器人和轻量关节的紧凑型 TTL 串行总线舵机，采用空心杯电机、金属齿轮和双轴输出结构，可用于 Microduck、Open Duck 类机器人原型。

## 关键参数

| 项目 | 参数 |
| --- | --- |
| 输入电压 | **5–8.4 V** |
| 堵转扭矩 | **10 kg·cm@6V** |
| 空载速度 | **0.09 s/60°（110 RPM）** |
| 控制接口 | `TTL 串行总线` |
| 电机 | 空心杯电机 |
| 齿轮 | 金属齿轮 |
| 输出结构 | 双轴 |
| 外形尺寸 | 34 × 20 × 23 mm |
| 重量 | 22.5 ± 2 g |
| 静态电流 | 21 mA |

!!! info "选型提示"
    堵转扭矩是短时极限值，不是持续工作点。多关节机器人应按同时动作时的峰值电流、工作周期、温升和冲击负载设计电源与结构余量。

## 适用场景

- Microduck、Open Duck 类小型双足机器人关节
- 机器人腿部、颈部和轻量夹爪
- 强化学习与 Sim2Real 运动控制实验
- 高校机器人实验室和具身智能原型
- 对安装空间和整机重量敏感的多关节机构

## 集成要点

1. 使用稳定的 5–8.4 V 电源，2S 锂电池满电电压为 8.4 V，不能继续升高。
2. 多舵机共用总线时设置唯一 ID，并为同时启动和受阻工况预留电流余量。
3. 安装前核对双轴结构、舵盘突出高度、安装孔位和关节零位；其他舵机的结构件通常不能直接替换。
4. 首次运动采用低速、小角度和无负载测试，再逐步增加运动范围。
5. 通信地址、控制模式和单位应以 HD-1910-C001 正式内存表及固件版本为准，不要直接套用其他系列。

## Open Duck 项目说明

HD-1910-C001 适合用于 Microduck/Open Duck 类轻量双足机器人，但更换舵机后仍需核对机械安装、电源、总线协议、零位、控制参数和强化学习策略。它不是其他品牌舵机或 STS3215 的直接无改装替代品。
