# 系列与接口

## 总线舵机

| 系列 | 物理层 | SDK 应用层 | 典型特点 |
| --- | --- | --- | --- |
| HD | TTL 半双工 | 以型号配套资料为准 | 紧凑型空心杯、金属齿轮和双轴结构，面向 Microduck、Open Duck 类轻量双足机器人 |
| SCS / SCSCL | TTL 半双工 | `SCSCL` | 常见为较低分辨率的位置总线舵机；以型号内存表为准 |
| STS | TTL 半双工 | `SMS_STS` | 多款磁编码、高分辨率或连续旋转产品 |
| SMS | RS485 | `SMS_STS` | 差分通信，适合更长线缆和更复杂电气环境 |
| HLS | TTL 半双工 | `HLSCL` | HLS 系列专用应用层与内存表 |

这些系列的数据包协议有相似之处，但**寄存器地址、数据意义和能力并非全部相同**。不要把另一系列的内存表直接套用到当前舵机。

## PWM 舵机

PWM 舵机通常由周期脉冲控制目标位置，不通过总线 ID 寻址。不同型号的允许脉宽、周期、电压、行程以及是否支持反馈可能不同。总线 SDK 与 FD 扫描流程不适用于普通 PWM 型号。

## TTL 与 RS485 不能直接互换

- TTL 总线通常为单端半双工，需要 TTL 调试板或正确设计的单线半双工电路。
- RS485 为差分总线，需要 RS485 收发器和正确的 A/B 接线。
- 不能仅靠改变软件波特率把一种物理接口变成另一种。
- 调试板、舵机与外部电源必须共地；RS485 终端和拓扑按具体系统设计。

## 型号确认清单

在提交技术支持问题或让 AI 写代码前，请记录：完整型号、标签照片、额定电压、物理接口、固件/内存表版本、当前 ID、当前波特率、调试板型号和控制平台。
