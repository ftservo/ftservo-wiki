# HD 系列规格

HD 系列面向 Microduck、Open Duck 类轻量双足机器人和紧凑型多关节机构，采用 TTL 串行总线，兼顾体积、重量和关节输出能力。

[返回规格目录](index.md) · [产品选型](../index.md)

!!! info "系列特点"
    紧凑型机身、空心杯电机、金属齿轮和双轴输出适合腿部、颈部和轻量夹爪。应用到开源机器人时，需要同时匹配机械结构、电源、通信协议和控制参数。
