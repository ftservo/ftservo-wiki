# 飞特舵机规格书目录

这里汇总 `FTServos/规格书` 中的全部 185 份 PDF，按现有文件夹分类。分类是资料管理方式，不等于已经核实的通信接口或在售状态。

请先按[产品选型](../index.md)明确需求，再打开对应 PDF，核对封面型号、版本、电压、尺寸和接口。相同产品可能存在多个文件版次；发布产品页前由产品工程师指定有效版本。

## 型号表与规格书的关系

`FTServos/型号.xlsx` 是型号清单，而 PDF 文件名常是规格书编号。两者有不一致项，不能以文件名自动推断额定参数、库存或兼容的 SDK。员工应建立经审核的型号与规格书映射，再制作可筛选的参数表。
