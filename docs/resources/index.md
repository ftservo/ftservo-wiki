## 产品页发布原则

每个产品页必须标明**完整销售型号、有效规格书版次、发布日期与工程审核人**。电压、针序、寄存器、分辨率、机械行程和保护设置都以该型号的正式资料为准。PDF 文件名只是资料编号，不能用来推断这些值。

曲线应附测试方法、测试条件和原始数据；3D 模型应附单位、坐标方向、版本、尺寸校验和许可状态。员工可复制[型号产品页模板](model-template.md)，按[Wiki 维护教程](../contributing.md)制作中英文页面并提交审核。
