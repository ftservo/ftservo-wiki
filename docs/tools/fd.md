# FD 舵机调试软件

FD 是飞特用于 Windows 的舵机配置与调试工具，可搜索设备、读取状态、修改 ID 和波特率、配置型号支持的参数，并进行基础运动测试。

[选择调试板](adapters.md){ .md-button }

官网提供 FD 1.9.8.2 离线版及 FD 1.9.8.3 等当前版本，同时提供 FE-URT 与 FE-SCPC 配套软件。请选择与调试板和舵机系列匹配的软件；版本、下载方式和文件密码以官网页面为准。

## 连接流程

1. 根据舵机选择 TTL、RS485、CAN 或 PWM 调试设备。
2. 安装调试板驱动，将调试板接入电脑。
3. 在舵机断电时连接信号、地线和外部电源，核对极性与针序。
4. 打开 FD，选择 Windows 设备管理器中显示的 COM 端口。
5. 选择设备当前波特率并打开串口。
6. 点击搜索；找到设备后停止搜索并选择目标设备。

## 修改 ID 或波特率

```text
总线只连接一只舵机 → 搜索 → 记录原参数 → 修改并保存
→ 断电重启 → 使用新参数重新搜索 → 确认结果
```

多个设备必须使用唯一 ID，并在同一总线上采用一致波特率。修改波特率后，FD 也要切换到新速率才能再次找到设备。

## 修改参数

FD 显示的项目取决于舵机型号和内存表。写入前：

- 保存原值或截图，便于恢复。
- 确认项目属于运行区还是持久化区。
- 从[通信协议](../reference/protocol.md)进入对应系列内存表，不要跨系列套用地址。
- 修改模式、限位、校准或保护参数后，按型号说明执行保存和重启。
- 首次运动采用低速、小位移，并保证机构无负载且运动范围内无人。

## 搜索不到设备

依次检查 COM 端口、驱动、串口占用、波特率、外部供电、接口类型、针序、共地、线缆和重复 ID。仍无法连接时，只保留一只设备，并换用已知良好的调试板、线缆和电源进行交叉验证。
