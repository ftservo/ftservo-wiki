# FD 舵机调试软件

FD 是飞特用于 Windows 的舵机配置与调试工具，可搜索设备、读取状态、修改 ID/波特率、查看或写入型号支持的参数，并进行基础运动测试。

## 连接流程

1. 根据舵机选择 TTL 或 RS485 调试板。
2. 安装调试板 USB 串口驱动，将调试板接入电脑。
3. 在舵机断电时连接总线和外部电源，核对极性。
4. 打开 FD，选择 Windows 设备管理器中出现的 COM 端口。
5. 选择设备当前波特率并打开串口。
6. 点击搜索；找到设备后停止搜索并选择目标设备。

## 修改 ID

同一总线出现重复 ID 时设备可能同时响应。安全做法是：

```text
总线只连接一只舵机 → 搜索 → 记录原参数 → 修改 ID → 保存
→ 断电重启 → 重新搜索 → 确认新 ID
```

修改波特率后，FD 也要切换到新波特率才能再次找到设备。多个设备最终必须使用唯一 ID 和相同波特率。

## 修改参数

FD 中显示的参数取决于舵机型号和内存表。写入前：

- 保存原值或截图，便于恢复。
- 确认参数是 RAM 还是 EEPROM/永久区。
- 不要套用另一系列的寄存器解释。
- 修改模式、限位、校准或保护参数后按说明书断电重启。
- 首次运动采用低速、小位移，并保证机构无负载。

## 搜索不到设备

依次检查 COM 口、驱动、串口占用、波特率、外部供电、接口类型、针序、共地、线缆、重复 ID。仍失败时，只保留一只设备并换用已知良好的调试板、线缆和电源交叉验证。
