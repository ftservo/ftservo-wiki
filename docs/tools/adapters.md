# 调试板与转换器

调试板用于连接电脑、控制器与飞特舵机。选择前先确认舵机的物理接口、供电电压和使用场景；TTL、RS485、CAN 与 PWM 接口不能直接互换。

## 产品一览

| 产品 | 主要用途 | 接口与关键参数 |
| --- | --- | --- |
| **FE-URT-2** `FE-URT2-C001` | USB 转 TTL/RS485 总线，配合 FD 软件调试总线舵机 | USB Type-C；UART 2.54 mm 排针；55.8 × 36.6 × 11.5 mm；12.5 g |
| **FE-SCPC-C003** | CAN 总线与 PWM 舵机编程 | USB-A 2.0；USB 5 V ±0.2 V 供电；50 bps–1 Mbps；55.2 × 22.2 × 9.6 mm |
| **AJ-6A00-C001** | 为调试连接提供可调直流电源 | 输入/输出范围 5–12 V；48 × 27 × 15 mm |
| **FE-FRS1-C001** | PWM 舵机双模式调试 | 4.8–25 V；39 × 38 × 8 mm |
| **FE-SNIS-C001** | 隔离 RS485 转 RS485/TTL 单总线 | DC 6–24 V；50 bps–1 Mbps；RS485 输入，TTL/RS485 输出；47.3 × 31 × 13.2 mm |

## 如何选择

| 使用场景 | 推荐设备 |
| --- | --- |
| 在 Windows 上搜索、配置和测试 TTL 或 RS485 总线舵机 | FE-URT-2 |
| 配置 CAN 总线产品或 PWM 舵机 | FE-SCPC-C003 |
| 调试 PWM 舵机并进行基础功能测试 | FE-FRS1-C001 |
| 需要 RS485 隔离或在 RS485 与 TTL 单总线之间转换 | FE-SNIS-C001 |
| 调试台需要 5–12 V 可调电源 | AJ-6A00-C001 |

## FE-URT-2 连接步骤

1. 从[官方软件下载页](https://www.feetechrc.com/service/software.html)安装对应驱动和 FD 软件。
2. 按舵机接口选择 TTL 或 RS485 端口，确认信号针序。
3. 舵机断电时连接信号线、地线和外部电源。
4. 使用外部电源为舵机供电，并确保电脑、调试板和电源共地。
5. 将 FE-URT-2 接入电脑，在 Windows 设备管理器中确认 COM 端口。
6. 打开 FD，选择 COM 端口和舵机当前波特率，然后搜索设备。

!!! warning "舵机电源"
    USB 接口主要用于通信和调试板供电。舵机应使用符合型号要求、容量充足的独立电源，不要把电机负载电流交给电脑 USB 端口承担。

## 调试安全

- 接线和更换接口前先关闭舵机电源，核对正负极和信号针序。
- 首次调试只连接一只舵机，确保总线中没有重复 ID。
- 机构留出运动空间，采用低速、小位移、无负载测试。
- 电压超过调试板或舵机允许范围时不要上电。
- 通信不稳定时依次检查接口类型、波特率、共地、线缆、供电压降和终端配置。
