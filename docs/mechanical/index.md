# 结构与装配

从完整型号的工程文件开始，依次完成安装接口、运动空间和装配验证。程序人员与结构人员使用同一型号、图纸版本、零位和允许行程。

## 按当前任务继续

| 现在要做什么 | 查看或准备 | 完成后应得到 |
| --- | --- | --- |
| 评估能否安装 | 型号页 → 结构设计 → 资料清单 | 正确后缀的外形、安装图和 STEP；缺项列清楚 |
| 设计支架与舵盘 | 安装基准、孔距、螺纹、旋入深度、输出轴及舵盘 | 可追溯版本的接口尺寸；不从产品照片测尺寸 |
| 检查关节运动 | 机械零位、电气零位、方向、可用行程、出线位置 | 全行程无干涉，线缆与插拔空间足够 |
| 完成装配交接 | 装配图、紧固要求、负载与工况、允许行程 | 可交给控制人员的装配与限位记录 |

## 工程文件怎么用

- **2D 安装图**：确认单位、基准、尺寸、公差、孔位及紧固要求，用于确定加工接口。
- **STEP / 3D 模型**：确认版本和坐标，进行装配与碰撞检查；与尺寸图不一致时请厂家确认。
- **STL**：先确认比例与单位，可用于展示或试装；网格不提供制造公差。
- **产品照片**：帮助识别连接器朝向、出线位置和实物后缀，不作为尺寸图替代品。

每个型号的附件状态见其资料表。标注“待补充”时，先向已有技术支持联系人索取本型号的文件，再继续加工设计；其他后缀的文件需要另行核实。

## 结构和程序共用的交接记录

| 交接项 | 记录内容 |
| --- | --- |
| 身份与版本 | 实物完整标签、图纸 / STEP / 支架版本、固件（如已知） |
| 零位与方向 | 机械参考面、安装零位、正方向、控制零位与机械零位的对应关系 |
| 动作边界 | 已确认的软件限位、硬限位与净空；未知值保持缺项 |
| 负载条件 | 方向、力臂、惯量或负载描述、工作周期和温升条件 |
| 验证记录 | 空载结果、装配后结果、干涉截图、异常与停止方式 |

堵转扭矩不能作为持续工作值；径向 / 轴向承载、舵盘和螺钉要求必须有本型号依据。先完成[对应控制路线的空载验证](../getting-started/index.md)，再装载并逐步验证机构。

## 遇到装配问题

先查看[安装干涉与零位排查](../troubleshooting.md#mechanical)，并附完整型号、文件版本及带标注的装配截图。只说“装不上”或“转不到”难以判断是图纸、零位、软限位还是实物版本问题。
