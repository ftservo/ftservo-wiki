# 快速开始

本流程面向第一次使用飞特总线舵机的用户。普通 PWM 舵机请使用与型号匹配的 PWM 控制器和脉宽范围。

## 准备物料

- 一只已确认型号的飞特总线舵机
- 与其物理接口匹配的 USB 调试板（TTL 或 RS485）
- 符合该型号电压和电流要求的独立电源
- 支持数据传输的 USB 线和总线连接线
- Windows 电脑（FD）或支持 Python/Arduino/Linux/STM32 的开发设备

## 第一次上电

1. 不连接机械负载，只连接一只舵机。
2. 断电状态下核对电源正负极、信号线和地线。
3. 先连接调试板与电脑，再给舵机侧外部电源上电。
4. 使用 FD 或 SDK 的 Ping 示例，以候选波特率搜索设备。
5. 记录原始 ID 和波特率；修改 ID 时总线上只保留这一只舵机。
6. 抬空输出轴或卸除连杆，以低速度、小位移做第一次运动。

!!! danger "堵转和反接可能损坏设备"
    USB 口不应承担舵机动力供电。电源反接、超压、长时间堵转、机构碰撞或重复 ID 导致的同时运动，均可能损坏舵机、调试板或电脑。
