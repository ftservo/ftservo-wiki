# 开始使用

先核对实物完整型号，再选择控制路线。准备接入程序和准备设计结构，可以从不同入口开始。

[查找我的型号](../products/index.md){ .md-button .md-button--primary }
[我要设计结构](../mechanical/index.md){ .md-button }

## 选择控制路线

| 实物资料确认的接口 | 从这里开始 | 首个完成标志 |
| --- | --- | --- |
| TTL / RS-485 总线 | [总线舵机入门](bus.md) | 单机身份与只读通信已确认，再验证小动作 |
| PWM | [PWM 舵机入门](pwm.md) | 针序与信号参数已确认，再验证中位/停止及小幅响应 |
| 接口或完整型号不确定 | [型号与系列识别](../products/series.md) | 获取匹配实物后缀的资料，暂不试探接线或发送动作 |

## 每一步都留下结果

| 阶段 | 本步需要 | 完成后记录 | 未通过时 |
| --- | --- | --- | --- |
| 型号确认 | 标签、后缀和资料版本 | 实物与文档对应关系 | 从型号页申请缺失资料 |
| 接线准备 | 电源、针序、适配器/控制器、共地 | 接线照片及实际配置 | [供电与接线](wiring.md) |
| 最小验证 | 空载、净空、准确控制参数 | 身份响应或 PWM 响应、异常与停止方法 | [按现象排查](../troubleshooting.md) |
| 程序集成 | 已验证配置与匹配示例 | 平台、代码版本、可复现记录 | [程序开发](../sdk/index.md) |
| 结构集成 | 图纸、模型、零位与允许行程 | 装配和干涉验证记录 | [结构与装配](../mechanical/index.md) |

有些型号目前只有规格摘要，专用针序、CAD 或示例尚未收录。先看型号页的资料状态，不将“待补充”当作通用参数可替代。
