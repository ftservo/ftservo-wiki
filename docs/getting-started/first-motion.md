# 第一次运动

第一次运动建议先在 FD 中完成，也可以运行对应 SDK 自带的示例。

## 安全步骤

1. 让机构卸载或把输出轴运动范围清空。
2. 确认读到的型号/ID 与目标一致。
3. 先读取当前位置，不立即写入远离当前位置的目标。
4. 设定较低速度和加速度（仅当该型号支持这些寄存器）。
5. 目标位置只偏移一个很小的量。
6. 观察电流、温度、声音和反馈；异常时立即断开动力电源。
7. 验证关闭扭矩/释放输出的方法，再逐步扩大运动范围。

## 位置值不是通用角度

不同系列可能采用不同位置分辨率、中心值、范围和方向编码。程序中的 `0`、`512`、`2048` 或 `4095` 不能脱离具体型号内存表解释。把角度转换成位置值之前，先确认：

- 有效原始位置范围
- 一圈或额定行程对应的计数
- 多圈/连续旋转模式
- 方向位或有符号速度的表达方式
- 机械软限位和零位

完成后再进入 [SDK](../sdk/index.md) 或 [协议与内存表](../reference/protocol.md)。
