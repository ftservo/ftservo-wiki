# 供电与接线

## 推荐拓扑

```text
电脑 USB ── USB 调试板 ── TTL/RS485 总线 ── 舵机
                         │                  │
                         └──── 共地 ────────┤
外部稳压电源 (+/-) ─────────────────────────┘
```

USB 主要负责通信；舵机动力由外部电源提供。具体接口针序必须看调试板和舵机说明书，不能只凭线色判断。

## 电源容量

- 电压必须落在该完整型号规定范围内。
- 电流按“同时动作数量 × 单机峰值需求”估算并留余量。
- 电源线过细、过长或接插件接触不良会造成压降、复位和通信错误。
- 多舵机项目建议分组供电，在总线附近做适当去耦，并保持可靠共地。
- 首次测试使用限流电源时，限流值不能低到一启动就跌压，也不要在未核实前盲目放大。

## 总线规则

- 同一总线上的 ID 必须唯一，波特率必须一致。
- TTL 与 RS485 必须使用对应的物理接口。
- 避免星形长分支和松动接头；复杂 RS485 网络需要结合线长与速率设计终端。
- 插拔舵机、电源或改接线前先断电。

## 上电前检查

| 检查项 | 应确认 |
| --- | --- |
| 型号 | 完整后缀与标签一致 |
| 电压 | 电源输出符合该型号数据表 |
| 极性 | V+、GND、信号/A/B 针序正确 |
| 接口 | TTL 调试板对 TTL；RS485 调试板对 RS485 |
| 机械 | 输出轴可安全运动，不会夹手或撞限位 |
| 总线 | 第一次只接一只舵机 |
