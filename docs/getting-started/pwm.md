# PWM 舵机入门

[返回入门路线](index.md) · [总线舵机入门](bus.md)

本流程适用于正式资料确认使用 PWM 的完整型号。PWM 不使用 FD 的总线发现、设备 ID、波特率或 SCS/STS/HLS 寄存器。

## 上电前拿到这些信息

| 必需信息 | 确认内容 |
| --- | --- |
| 完整型号与工作方式 | 后缀、角度控制或转速控制、适用资料版本 |
| 供电与连接 | 允许输入范围、电流要求、连接器朝向、针序、共地 |
| 控制信号 | 电平、周期、脉宽上下限、中位/停止值、丢信号行为 |
| 机械边界 | 允许行程、方向、净空、负载状态与断电方式 |

请在[型号页](../products/index.md)查看资料清单。没有周期或脉宽依据时，不默认套用其他舵机的数值，不进行全范围扫描。

## 首次验证

1. 断电接线，主控 PWM 输出保持关闭；按正式资料确认极性、共地和信号电平。
2. 脱开连杆或负载，预留可能的上电动作空间，并保证能立即切断动力电源。
3. 按已确认的周期与中位/停止值配置控制器，不将“角度零点”和“电机停止”混为一谈。
4. 输出确认过的最小测试信号，观察是否符合该型号的角度/转速响应。
5. 在有依据的范围内做小幅变化，记录方向、响应和异常。通过后再建立程序限位并接入机构。

## 完成后应有的记录

记录型号及后缀、控制器与工具链、供电、针序图版本、实际周期/脉宽、空载结果、停止方式与日期。共享 PWM 库的默认参数不能作为本型号验证记录。
