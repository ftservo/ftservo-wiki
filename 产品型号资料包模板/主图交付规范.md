# 舵机产品主图交付规范

用于 Wiki 产品卡片和型号概览。构图参照[HL-3950-C001 实际主图](../docs/products/models/hl-3950-c001/images/main.webp)。

| 项目 | 交付要求 |
| --- | --- |
| 网站成品 | **800×800 px，1:1 正方形，WebP，文件名 `main.webp`** |
| 背景 | 纯白色 `#FFFFFF`，不加边框或大面积装饰 |
| 主体比例 | 产品最长方向占画面 75%–85%，目标 80%（800px 画布中约 640px） |
| 留白 | 产品居中；最长方向两端各约 80px。细长产品另一方向留白更大是正常的，不拉伸产品 |
| 完整性 | 输出轴、安装耳、外壳均完整保留；产品结构、标签和型号文字保持真实 |
| 视角 | 参考样例的斜侧视角，兼顾正面标签、输出轴和机身厚度；同类产品尽量统一朝向 |
| 附加内容 | 不叠加宣传文案、尺寸线、额外 Logo 或水印；保留实物上的原有标识 |
| 压缩 | WebP 质量建议 85–92，优先保证标签清晰，通常控制在 100KB 内 |
| 原始文件 | 同时保留 PNG / PSD 高分辨率源文件，建议至少 1600×1600 px；网站导出 800×800，不靠放大低清图补细节 |

本次样例由现有照片裁去外围留白，再导出为 800×800；没有重绘产品结构。后续请从高分辨率实拍或经过确认的产品渲染源图制作。

交给管理员后，同一张图片同步放入中文和英文型号的 `images/main.webp`，并更新选型数据的 `image` 字段。具体步骤见[维护教程](../WIKI更新维护教程.md#更新主图)。
