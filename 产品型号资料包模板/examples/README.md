# 型号验证示例交付要求

只有完成对应型号实物验证后，才在 `manifest.json` 将示例设为 `available`。可将多个文件及此说明打成一个示例 ZIP，清单指向该 ZIP；不要只登记代码而漏掉依赖与运行说明。

| 项目 | 工程师填写 |
| --- | --- |
| 完整型号、后缀、固件版本 | 待确认 |
| 平台、系统、编译器 / 解释器版本 | 待确认 |
| SDK 仓库、提交号、应用层 | 总线型号填写；PWM 说明定时器配置 |
| 电源、适配器、针序图版本 | 待确认 |
| 端口、ID、波特率或 PWM 参数 | 写明来源，不猜测默认值 |
| 安装依赖和运行命令 | 待填写 |
| 初始状态、预期响应与停止方法 | 待填写 |
| 实物测试日期、条件、结果 | 未验证 |

先提供只读识别或读取示例。涉及运动的示例必须明确电源、共地、接口、参数来源、机械净空和动作范围；不要将未知寄存器地址或行程作为可执行默认值。
