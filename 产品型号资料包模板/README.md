# 产品型号资料包模板 · 填写说明

此文件夹用于收集一个**完整型号及后缀**的开发资料。工程师可离线填写后交付管理员，不需要 GitHub 账号。模板中的“待确认”和空目录不代表产品已经提供对应功能或文件。

## 交付结构

```text
<型号-id>/
├─ main.md               # 型号概览、规格、资料下载、支持信息
├─ software.md           # 型号接线、控制路线、验证记录
├─ mechanical.md         # 安装接口、CAD 使用、装配检查
├─ manifest.json         # 型号身份与附件状态；中英文一致
├─ en/                   # 英文页面草稿，管理员拆分到 docs/en/...
│  ├─ main.md
│  ├─ software.md
│  ├─ mechanical.md
│  └─ manifest.json
├─ datasheets/           # 正式规格书、批准版本说明
├─ electrical/           # 针序、接线、型号内存表与固件说明
├─ drawings/             # 带尺寸与公差的 PDF / DXF / DWG
├─ models/               # STEP 优先；其他格式注明用途
├─ images/               # 首图、接口朝向、装配图
├─ examples/             # 经本型号验证的最小示例及依赖说明
└─ tests/                # 测试条件、验证记录、原始结果
```

现有型号根目录中的 `test-result.json` 保持兼容。新增测试也可放入 `tests/`，但需要同步附件清单和曲线的 `data-source`。可选目录只有收到真实文件后才需要纳入 Wiki，不必给每个型号提交空目录。

## 填写顺序

1. 将资料包重命名为小写型号 ID，例如 `st-3215-c001`。不要去掉区分电压、接口或结构的后缀。
2. 替换中英文三个页面中的 `MODEL-ID` 与编辑提示。在两份 `manifest.json` 中填写相同的 `model_id`、实物 / 文档型号名称、系列、物理接口与文档版本。
3. 把有来源的文件放进对应目录。将该类附件的 `status` 改为 `available`，填写准确的 `path`、`revision`、`source`。未取得文件保留 `missing` 和 `path: null`；确实不适用才用 `not_applicable`。
4. PWM 使用 PWM 路线，将 `memory_table` 标为 `not_applicable`；总线型号选择经过确认的系列应用层。未知时不套用其他系列。
5. 修改正文中的资料缺项描述，使其与实际附件一致。模型、程序、供电与动作限制必须由对应工程师确认；没有验证过的示例不能标注“已验证”。
6. 补齐 `sources`，记录文档名称、版本、页码 / 章节及适用型号。来源清单中现有目录条目仅说明数据出处，不等于批准证明。
7. 管理员按根目录《WIKI更新维护教程.md》拆分中英文目录，刷新资源表并运行检查后发布。

## 文件命名与引用

- 文件名使用小写英文、数字和连字符，保留版本，如 `mounting-r1.pdf`、`housing-r1.step`；不要同名覆盖导致客户混用修订。
- Markdown 中链接用文件相对路径，如 `[安装图](drawings/mounting-r1.pdf)`；只有文件真实存在时才添加链接。
- 图片用 `![接口朝向](images/connector-r1.png)`，尺寸图应注明单位；没有图片时保留文字缺项说明，不放破图占位。
- HTML 曲线在 `main.md` 渲染后的 URL 是 `<型号>/main/`，所以使用 `data-source="../test-result.json"` 或 `../tests/<文件>.json`；不要误改成 Markdown 的路径规则。
- 模板不包含可直接执行的运动代码。示例应注明平台、依赖、固件、SDK 提交号、实物型号、接线、参数来源和验证日期。

## 交付前复核

先只读通信 / 明确 PWM 信号，再无负载的小动作；机械人员确认图纸、STEP、安装零位与行程；测试人员记录样本、供电、环境和负载。目录参数、单次测试、连续额定能力分别描述，不互相替代。

所有已收录共享附件在中英文目录中保持相同字节；需要发布中英文独立 PDF 时，可提供同一个包含两种语言的文档包，并在清单中指向该包。工程草稿、客户信息和凭据不能放入发布目录。
